Implementación de una aplicación móvil para los conductores en terreno. Permite gestionar las
rutas del día, registrar cada visita, capturar evidencia fotográfica y actualizar el estado de las
recolecciones en tiempo real.

Está desarrollada con AppSheet y conectada a una base de datos MySQL.
