Sitio estático que reúne mis proyectos. Cada proyecto es un archivo Markdown validado por un schema
tipado, así que agregar uno nuevo no requiere tocar código.

Lo desarrollé con un flujo spec-driven: constitución, especificación, plan y tareas aprobadas
antes de escribir código, usando GitHub Spec Kit.
