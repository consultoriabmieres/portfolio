Desarrollo y puesta en marcha de una solución para gestionar la recolección y la logística de la
empresa. Tiene un portal interno para los operadores y un portal externo para los clientes.

El backend en Django se integra con la Google Maps Geocoding API para geocodificar direcciones y
apoyar la gestión de rutas y locales. El frontend está hecho con Vue.js.
